# Zig + Raylib + Wasm

Run a [Raylib](https://www.raylib.com/) game written in [Zig](https://ziglang.org/), in your browser using Wasm.

This repo is a template for building a Raylib game for web, using Zig lang.

## Commads

Make file provides some covenience commands:

```zsh
Usage:
  make <target>

Targets:
  help        display this help message
  build       build the project
  build-web   build project for web
  run         run the project
  run-web     run the project in web server
```
